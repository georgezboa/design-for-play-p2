exhibit, which uses the same panel engine): the bezel round each window, the
walnut wall, the panel trim, the rails and the lamp shades.

Generated by George with ChatGPT/Codex image generation (OpenAI), 2026-10-08.

Every file here is rebuilt from the source sheet by

    python3 -I scripts/ch1-art/chrome-build.py [--src DIR] [--preview DIR]

`--src` defaults to `$NIGHTFALL_ART_SRC`, or `/home/claude/art-src/ch1` if that
is unset. When George replaces `C-bezel.png`, run the script again. If the
atlas geometry it prints changes, copy `chrome.json`'s numbers into
`CHROME_ATLAS` in `src/chapters/nightService/art/wallArt.js`.
`tests/nightService/chrome.test.mjs` fails until the two agree.
