# NIGHTFALL CHAPTER 1 PHASE V–VI — PLAYABLE SEQUENCE LOCK

**Status:** READY / USER CORRECTION 2026-08-06  
**Preserves:** the accepted Phase IV `THE FIRST WEIGHT` implementation  
**Supersedes:** all reachable Phase V/VI rolling-bearing service-table panels

## Shared rule

Both phases remain inside the carriage. The player, cases, exit, amber cable,
cyan hose, cradles and equalizing beam share one frame. There is no modal
inspection table, gauge objective, button row, launched bearing, A/B checklist,
red warning card or new interaction verb.

## Phase V — TWO TRUE THINGS

### Five-second read

1. Two archive cases occupy one overloaded main cradle.
2. Their witness tags carry the same pattern but the window memories disagree.
3. A white Archivist frame points toward an open jettison hatch on the right.
4. The train knocks open a folded second cradle.
5. The existing amber lead and cyan hose visibly stop short of that cradle.

### Golden path

1. Punch both case tags. Each punch preserves a different short window memory.
2. The second cradle unfolds but visibly hangs unsupported.
3. Attach the amber lead. The winch pulls the cradle into horizontal alignment,
   but without air it sags back under weight.
4. Attach the cyan hose. The cushion inflates and supports the cradle, but
   without the winch it drifts away from its loading position.
5. With both relationships present, carry either punched case from the main
   cradle onto the second. One case on each support holds level for 600ms and
   closes the jettison hatch.

Amber and cyan have no hidden order. Every incomplete combination remains
visible and reversible. A case placed on an unsupported cradle returns slowly
to its last witnessed bracket; tags and connections persist.

## Phase VI — THE TRAIN REMEMBERS

### Five-second read

1. The same two cradles, cable, hose, cases and equalizing beam remain.
2. The windows start moving; this is the same train, now alive.
3. An amber echo case repeats the large left/right placements learned in IV.
4. A present case rests on the opposite cradle and can be carried with the same
   Phase IV grip/release verb.
5. Beam angle, suspension and lamp motion continuously show whether past and
   present counterbalance.

### Golden path

1. Past settles right; place the present case left and hold level for 650ms.
2. Past crosses left; move the present case right and hold level for 650ms.
3. The Archivist erases the middle of the amber echo. Its case begins to fall
   near the exit. The present case locks where the player left it.
4. Leave the balanced position, run to the falling case and press E to catch it.
5. The train reuses the V winch to make the missing counter-movement itself.
   The beam levels, both supports lock, the door opens and the train departs.

The falling case waits in a recoverable slow fall; there is no lethal timing
window. VI adds no route switch, TEST control, timing bar or new tool.

## Acceptance

- A new player can describe V as “I built room for both memories,” not “I ran a
  machine test.”
- A new player can describe VI as “my past movement and present case balanced
  each other; then the train copied me to help,” not “I hit a timing window.”
- Start and exit remain visible; all progress survives wrong placement.
- Phase IV files and behavior remain unchanged except for exporting its case
  movement trace for VI.
